# Meeting Minutes — Team 012-0

One file for the whole project. Add a new section at the top after every weekly TA meeting, on
the day of the meeting. The scribe writes it, and it's a good idea to rotate the scribe each
week.

This file exists from Lab 8 onward, even before the first meeting: git does not track an empty
folder, so without a file `TeamMeetingLogs/` never reaches GitHub.
