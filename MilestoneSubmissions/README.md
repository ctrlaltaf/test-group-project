# MilestoneSubmissions

Every course document the team submits goes here. Not code (that's `ProjectSourceCode/`) and
not meeting minutes (that's `TeamMeetingLogs/`).

Put the team number in every filename. It has to appear on every deliverable.

## What lands here, and when

| When | File | What it is |
| --- | --- | --- |
| Lab 8 | `ProjectProposal_012-0.md` | The proposal: items 1–13, plus the extra credit if you do it |
| Every weekly TA meeting | `ReleaseNotes.md` | What changed since the last meeting. One file, newest week at the top |
| Later labs | as each writeup names it | Requirements, test plan, and so on |
| Dec 4 | `ProjectPresentation_012-0.pdf` | PDF of the presentation slides |
| Dec 4 | `ProjectReport_012-0.pdf` | The final report, 8–10 pages |

Replace `012-0` with your own team number. The two PDF names come from the project guide, so
match them exactly.

## Before each TA meeting

`ReleaseNotes.md` is graded at every weekly meeting. Update it before you walk in, not after.
